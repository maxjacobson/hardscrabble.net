I've added a "Uses" page to this site at [/uses](/uses). This shares out the stuff that I use, specifically computer stuff. Of course I use all kinds of other stuff.

This is a thing that other blogs have, and I thought it would be fun to participate. You can see a list of all kinds of "slash pages" here: <https://slashpages.net/#uses>. I'm not making all of those but I'll make this one.

I previously blogged about this once before, in 2017: [the hardware and software I use (2017)](/2017/the-hardware-and-software-i-use/). It's been long enough that plenty has changed, but it's fun to see what hasn't. I'm still using the same monitor, Fastmail, NearlyFreeSpeech.net. This site is still built with Jekyll and hosted on GitHub pages.

I'll try to remember to update my uses page once or twice a year going forward.
